# SoundSpace

 Приложение служит интеллектуальной прослойкой между клиентом и Qobuz API, обеспечивая быструю доставку аудиоконтента.

##  Архитектура
Проект реализован в соответствии с современными стандартами разработки на Java:
- **Reactive Backend:** Асинхронная обработка запросов на базе Spring WebFlux.
- **BFF Pattern:** Сервер выступает в роли доверенной точки входа, управляющей интеграцией с внешними API и агрегацией данных.
- **UI:** Плавный пользовательский интерфейс, обслуживаемый через статические ресурсы Spring MVC.

## Технологический стек
* **Java 17**
* **Maven** — сборка и управление зависимостями.
* **Spring Boot 3.4.1**
* **Spring WebFlux** — non-blocking I/O взаимодействие.
* **Qobuz API 0.2** — интеграция с музыкальным каталогом.

## Структура проекта
* `src/main/java/com/soundowner/controller` — REST-эндпоинты и маршрутизация.
* `src/main/java/com/soundowner/service` — Бизнес-логика и реактивные клиенты.
* `src/main/resources/static` — Фронтенд (HTML/CSS/JS).
